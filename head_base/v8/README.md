# Head Base V8：v7 加上表情形態鍵

2026-10-30。從 v7 出發，只新增臉部表情形態鍵。骨架、捏臉滑桿、體型、舉手修正鍵和貼圖都跟 v7 一樣。

## 新增內容

- **33 個表情形態鍵**，名稱都以 `ex_` 開頭，預設值 0。
  - 來源是 MPFB 內建的表情單元（expression/units/asian，MakeHuman 原雕，CC0）。
  - 分布：眼睛 6 個、眉毛 8 個、嘴巴 13 個、鼻子 6 個。
  - body 有 33 個，brows 15 個，lashes 14 個。同名的鍵要同時設到 body、brows、lashes 三個物件上。
  - 眼球物件沒有表情鍵：眼球轉向直接轉 eye 物件。
- **轉移方法：** v7 的每個頂點投影到 v5 MPFB 網格最近的表面，再用重心座標內插 MPFB 的表情位移。
  - v7 臉部大多和 v5 頂點重合，這些點拿到的就是原始位移。
  - 腳本在 `scripts/transfer_mpfb_expr.py`。
- **expressions.json：** 每個鍵的來源、適用物件、最大位移、建議上限，以及 6 個表情組合（presets）。

## 表情組合（presets）

| 名稱 | 組成 |
|---|---|
| blink | 左右 closure 各 1 |
| smile | corner_puller 0.8 + 左右 slit 0.3 |
| laugh | corner_puller 0.9 + mouth_open 0.35 + slit 0.5 + 挑眉 0.3 |
| sad | 左右眉頭上抬 1 + mouth_depression 0.6 |
| angry | 左右皺眉 1 + mouth_compression 0.5 + 鼻翼上提 0.4 |
| surprise | 挑眉 1 + 睜大 1 + mouth_open 0.3 |

對照圖：`compare_vs_v7.png`，第一欄是 v7 中性臉，後面依序是 6 個組合，三列分別是正面貼皮、斜側貼皮、正面灰模。每個表情單元的近拍在 `review/units_*.png`。

## 已知問題 / 限制

1. **閉眼時上眼皮是一片深色。**
   - 閉眼的形狀是對的：灰模上眼皮完整蓋住眼球。
   - 原因是 v7 的粗眼線畫在上眼皮皮膚上，正面看約 4 mm 高。睜眼時那片皮膚被壓扁，看起來是眼線；閉眼時轉到正面，就露出整片。
   - 需要 ideal_hero 重畫眼皮貼圖：眼線靠緊睫毛根部，其餘是膚色。調形態鍵或權重修不掉。
2. **張嘴：**
   - 嘴裡只有原本淺淺的口腔內袋，看得到平坦的後壁。牙齒、舌頭、口腔零件還沒做。
   - `ex_mouth_open` 滿值是 41 mm（尖叫），建議上限 0.5。
3. **neck-platysma 沒收：** 脖子在轉移範圍的邊界有接縫。
4. **表情只在中性體型上檢查過：**
   - 4 種體型的形態鍵不影響頭部。
   - 42 個捏臉鍵和表情鍵疊加，還沒有逐一驗證，例如眼睛放大後再閉眼。
5. **FBX 是 Blender 重新匯出的：** 匯入 Blender 檢查，骨頭 52 根、形態鍵數量和預設 0 都正確，靜止姿勢和 v7 最大差 0.0005 mm。Unity 實機還沒測。

## 驗證

- **.blend：** 靜止姿勢和 v7 逐頂點相同，差 0 mm。
- **FBX：** 重新匯入後，各形態鍵預設 0。
- **glb：** JSON 內預設權重全部是 0；各物件的形態鍵數為 body 89、brows 57、eye 42、lashes 56。
